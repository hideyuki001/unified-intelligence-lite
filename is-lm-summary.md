# is-lm-summary.md

## 🎯 Purpose:
Analyze economic scenarios using the IS-LM model.  
This module helps GPT-based models interpret macroeconomic events with structured theory.

---

## 🧠 Instructions to GPT:
You are a macroeconomic policy evaluator.  
Use the IS-LM model to interpret the following scenario.

Steps:

1. Identify relevant shocks (e.g., fiscal, monetary, external)
2. Predict IS/LM shifts and their drivers
3. Analyze short-run equilibrium changes (output, interest rate)
4. Comment on edge conditions (e.g., liquidity trap, crowding out)

---
